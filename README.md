Welcome to the repository for **StockSense**. This project is a modern, intuitive, and highly interactive Inventory Management System designed to streamline stock tracking, operations, and business analytics with a rich user experience.

🔗 **Live Demo:** [https://stocksense.web.app](https://stocksense.web.app) *(Replace with your actual link if deployed)*

---

## 🌟 Features

- **Modern & Immersive UI:** Sleek glassmorphism design with fluid animations powered by Framer Motion.
- **Dynamic Dashboard & Analytics:** Real-time KPI tracking, inventory status alerts, and beautifully organized metrics.
- **Real-time Currency Conversion:** Instantly convert product prices across multiple global currencies using live exchange rates via backend integration.
- **Advanced Product Catalog:** Visual grid layout for products featuring dynamic searching, filtering, and automated low-stock indicators.
- **Comprehensive Operations Management:** Track incoming receipts, outgoing deliveries, and internal stock adjustments in a searchable, dynamic transaction ledger.
- **Authentication & Security:** Built-in email/password registration alongside seamless Google OAuth integration.
- **Contact Form Integration:** Connected to Web3Forms for reliable and seamless user messaging.

---

## 🛠️ Tech Stack

This project is structured as a full-stack application.

**Frontend (`/client`)**
- React 19 + TypeScript
- Vite (Build Tool)
- Tailwind CSS (Styling)
- Framer Motion (Animations)
- React Router (Navigation)
- Google OAuth (Authentication)

**Backend (`/server`)**
- Node.js + Express.js
- Custom API Integrations (Open Exchange Rates)
- RESTful Architecture
